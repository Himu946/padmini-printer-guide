PadminiVna Printer Guide

Secure printing, scanning, scan retrieval and printer setup.

Security: Keep your six-digit code private. Collect your pages and sign out when finished.

1. Create your unique print code

Use your Windows login on a company computer.

Open this address in a browser

http://198.9.200.200/ad-authenticator/mycode.aspx

Sign in

Enter your Windows login user ID and Windows password, then select Sign In.

Select New code

A six-digit code appears. Keep it private and use it when the printer requests a code.

This internal address may only work on the company network.

2. Print using HP AC Secure Pull Print

Submit the job on your computer, then release it at the printer.

Send your document

Select Print, choose the corporate PullPrint printer and submit the job.

Select HP AC Secure Pull Print

At the printer touchscreen, tap HP AC Secure Pull Print.

Enter your six-digit code

Your user name and queued jobs should appear.

Choose an action
  • Print All: prints all jobs in your queue.
  • Print-Delete: prints the selected job and removes it from the queue.
  • Print-Keep: prints the selected job and keeps it queued.
  • Delete: removes the selected job without printing.
Collect pages and sign out

Return to the home screen and select Sign Out.

Tip: Use Print-Delete for a one-time job you do not need to print again.

3. Scan to your department folder

Follow these steps on the printer touchscreen.

Select Scan

Tap Scan, then choose Scan to Network Folder.

Enter your secure code

Enter your six-digit code when prompted.

Load your department

Tap Load, select your department, then tap Load again to confirm.

Check options and send

Set the file name if needed. For two-sided originals, choose 2-sided / Both Sides in scan options if available, then tap Send.

Sign out

Sign out from the printer after scanning.

Two-sided scanning: The supplied manual does not show the exact screen for this setting. Check scan options before tapping Send.

Find scanned files on a Windows computer

Open Run

Press Windows + R.

Enter the network path

Type \\198.9.200.201 and press Enter.

Open your department folder

Open the Scan folder inside your department folder.

This is an internal network share and may not be accessible from phones or outside the company network.

4. Install HP LaserJet PullPrint

On a Windows computer connected to the company network.

Open Run

Press Windows + R.

Open the printer server

Enter \\198.9.200.200 and press Enter.

Connect to PullPrint

Right-click PullPrint and choose Connect.

Wait for installation

Allow a few minutes for installation to finish.

Optional: set as default

Open Control Panel → Devices and Printers. Right-click PullPrinter and select Set as default printer.

If the server path or connection fails, contact IT support.

Troubleshooting

Select the issue you are experiencing.

My code is not accepted

Generate a new code from the internal code page and try again. If it still fails, contact IT.

My print job is missing

Check that you sent the job to PullPrint on your computer. Wait briefly and reopen the secure queue. Contact IT if it remains missing.

My scan is missing

Confirm the correct department was loaded before Send. On a work computer, open \\198.9.200.201, then your department folder and Scan folder.

The back side was not scanned

Open scan options and select 2-sided / Both Sides, if available, before Send.

I cannot open a network path

The paths are internal company resources. Connect to the company network or contact IT support.
